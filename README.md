# ScreenFree Writer

一个专注于写作的iOS应用，提供简洁的界面和强大的功能。

## 主要功能

1. 纯文本编辑
   - 简洁的编辑界面
   - 支持Markdown格式
   - 自动保存

2. 编辑历史
   - 撤销/重做功能
   - 历史版本管理

3. 云同步
   - iCloud同步支持
   - 多设备数据同步

4. 文件管理
   - 文件夹组织
   - 文件分类管理
   - 标签系统

5. 搜索功能
   - 全文搜索
   - 替换功能
   - 高级过滤选项

6. 写作辅助
   - 实时字数统计
   - 阅读时间估算
   - 段落统计

7. AI辅助
   - 智能错别字检测
   - 快捷键触发
   - 写作建议

8. 文本对比
   - 侧边栏修改建议
   - 一键采纳/拒绝
   - 修改历史追踪

9. 语音功能
   - 文本朗读
   - 错别字提示
   - 语音控制

## 技术栈

- SwiftUI
- CoreData
- CloudKit
- AVFoundation
- Natural Language Framework

## 系统要求

- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+
